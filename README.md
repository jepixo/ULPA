# [ulpa](https://jepixo.github.io/ULPA/)
### University of Limerick Postgraduate Accommodation Guide

**ulpa** is a modern, responsive web application designed to help postgraduate students at the University of Limerick find the best on-campus and off-campus accommodation.

Created by **jepixo**.

---

## Features

### 🔍 Real-Time Search & Filtering
Instantly filter properties by **Location** (On-Campus vs. Off-Campus), **Room Type**, and **Amenities**.

### 📱 Modern Interactive UI
- **Accordion Cards**: Browse properties quickly with expandable details, avoiding clutter.
- **Premium Details Page**: each property has a dedicated, immersive page with high-quality images and video tours.
- **Responsive Design**: optimized for mobile, tablet, and desktop.

### ⚡ Fast & Lightweight
Built with **Vite** and **React** for lightning-fast performance.

---

## Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS (Custom Pantone Green Theme)
- **Routing**: React Router DOM
- **Typography**: "Outfit" (Google Fonts)

---

## Getting Started

### Prerequisites
- Node.js (v18+)

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/jepixo/ulpa.git
    cd ulpa
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Run the development server:
    ```bash
    npm run dev
    ```

4.  Open `http://localhost:5173` in your browser.
